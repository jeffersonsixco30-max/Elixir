¿Qué es JavaScript?

Lenguaje de programación que da comportamiento e interactividad a las páginas web. HTML es la estructura, CSS el estilo y JS el comportamiento.

Conceptos básicos

  • Variables: guardan datos (let nombre = "Ana").
  • Funciones: bloques de código reutilizables.
  • Eventos: reacciones a click, hover, etc.

Ejemplo práctico

<button id="b">Click</button>
<script>
  let veces = 0;                               // variable
  function sumar(){ veces++; alert(veces); }   // función
  document.getElementById("b").addEventListener("click", sumar); // evento
</script>
