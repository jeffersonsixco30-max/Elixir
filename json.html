¿Qué es JSON?

Formato de texto ligero para intercambiar datos. Es el estándar porque es fácil de leer y casi todos los lenguajes lo entienden. Usa pares clave-valor, objetos {} y arreglos [].

Objeto JS vs cadena JSON

Objeto JS
const p = {
  nombre: "Jersey Web",
  marca: "Elixir",
  precio: 35
};
JSON
{"nombre": "Jersey Web",
 "marca": "Elixir",
 "precio": 35}
JSON.stringify(p)  // objeto → texto
JSON.parse(texto)  // texto → objeto

Uso en la web

El navegador pide datos a un servidor o API con fetch() y este responde en JSON. Así funciona, por ejemplo, el webhook de Discord de este sitio.

fetch("https://api.example.com/datos")
  .then(r => r.json())
  .then(d => console.log(d));
