¿Qué es jQuery?

Librería de JavaScript creada en 2006 por John Resig para simplificar el manejo del DOM y lograr que el código funcionara igual en todos los navegadores. Su sintaxis usa el símbolo $.

JS vanilla vs jQuery

FunciónJS VanillajQuery
Seleccionardocument.querySelector("#a")$("#a")
Ocultarel.style.display = "none"$("#a").hide()
Clickel.addEventListener("click", f)$("#a").click(f)

Ventajas: código más corto y efectos fáciles. Desventajas: pesa más y el JavaScript moderno ya hace casi todo lo mismo.
